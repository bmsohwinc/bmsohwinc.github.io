Lab 3: Color Adjustment in Monitors

Name: [Your name]
NetID: [Your NetID]

Code Plan

  1. Declare integer variables red, green, and blue.
  2. Read the three input values into these variables.
  3. Declare integer variables min1 and min2.
  4. Compare red and green. Store the smaller value in min1.
  5. Compare min1 and blue. Store the smaller value in min2, the gray component.
  6. Declare integer variables newRed, newGreen, and newBlue.
  7. Subtract min2 from red, green, and blue, and store the results in newRed, newGreen, and newBlue.
  8. Print the adjusted red, green, and blue values, separated by spaces, followed by a newline.

Code

#include <iostream>
using namespace std;

int main() {
    int red, green, blue;
    cin >> red >> green >> blue;

    int min1, min2;

    if (red <= green) {
        min1 = red;
    } else {
        min1 = green;
    }

    if (min1 <= blue) {
        min2 = min1;
    } else {
        min2 = blue;
    }

    int newRed, newGreen, newBlue;

    newRed = red - min2;
    newGreen = green - min2;
    newBlue = blue - min2;

    cout << newRed << " " << newGreen << " " << newBlue << "\n";

    return 0;
}

Dry Run (optional, for your reference only)

Input: 130 50 130. Expected output: 80 0 80.

  1. Read red = 130, green = 50, and blue = 130.
  2. red <= green is false, so the else branch sets min1 = 50.
  3. min1 <= blue is true, so min2 = 50.
  4. Subtract 50: newRed = 80, newGreen = 0, and newBlue = 80.
  5. Print 80 0 80, followed by a newline. This matches the expected output.
